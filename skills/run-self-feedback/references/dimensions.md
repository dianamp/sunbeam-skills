# Feedback dimensions

What to look for in a transcript, by call type. Each dimension lists the behavior, how to spot it in text, and a rough "good looks like" bar. Benchmarks come from conversation-intelligence research (Gong Labs on ~326K sales calls, Rafiki/SalesArmor metric definitions), the ICF coaching competencies, and standard meeting-facilitation practice. Treat them as reference points, not rules — a coaching call and a discovery call should not have the same talk ratio.

Not every dimension applies to every call. Pick the ones the transcript actually gives evidence for.

## Dimensions that apply to every call

| Dimension | How to spot it | Good looks like |
|---|---|---|
| **Talk / listen share** | Rough word count per speaker. | Sales & coaching: user talks < 50% (Gong "golden" ratio ≈ 43/57; losing calls trend ≥ 60%). Advisory where the user is the expert: higher is fine, but watch monologue length. |
| **Longest monologue** | Longest uninterrupted stretch of the user's speech. | Under ~75 seconds (≈ 200 words) in discovery. Longer is OK when explaining a recommendation, if it was asked for. |
| **Questions before answers** | Count open questions the user asks before their first recommendation. | Several open ("what / how / tell me more") questions before any "you should". |
| **Presence** | "Say that again", "I wasn't listening", "sorry, I was…", joining late, tech excuses, searching docs live while advising. | Zero. Each one tells the other person they don't have full attention. |
| **Interrupting / finishing sentences** | User's turn starts while the other speaker's thought is clearly unfinished (mid-sentence, trailing "and…"). Diarization makes this fuzzy — only flag clear cases. | Rare. Waiting 1–3 seconds after someone finishes is the benchmark ("patience"). |
| **Hedging & self-discounting** | "I'm not an expert", "take this with a grain of salt", "it's been a couple years", "I don't know if this is right, but". | Absent around advice and pricing. Caveats after the recommendation, not before. |
| **Recommendation-first** | Does the user's answer to "what should we do?" start with the answer, or with a think-aloud? | First sentence = the recommendation. Second = why. Caveats last. If the other person has to say "so your opinion is…", it was buried. |
| **Agenda & time** | Did the user state an agenda in the first minute? Announce hard stops up front? Steer back when drifting? Did the call run long? | Agenda stated, hard stops announced at the top, drift redirected within a minute. |
| **Next steps & owners** | Last few minutes: are actions concrete, dated, and assigned by name? | Every action has an owner and a date. "I'll take that on" beats "we should". |
| **Follow-through** | Did commitments from earlier calls come up and get closed? Did last week's review goal show up? | User raises their own prior commitments before being asked. |
| **Rapport** | Genuine check-in, humor, remembering personal details, acknowledging the other person's point before disagreeing. | Warm, brief, then to work. Not a performance. |

## Sales calls (prospects, proposals, pricing)

| Dimension | How to spot it | Good looks like |
|---|---|---|
| **Discovery depth** | Number and type of questions before describing services. Do questions dig into pain, cost of inaction, who decides, what they've tried? | 11–16 real questions in a discovery call, spread through the call, not front-loaded. At least one question that gets the prospect to name a number (cost, time, risk). |
| **Value statement** | When the user explains what they do: is it one or two sentences about the buyer's outcome, or a tour of deliverables and history? | Short, outcome-first, then stops and asks a question. |
| **Pricing & scope** | When price comes up: stated plainly with a number, or wrapped in qualifiers? Did the user offer options (cheaper/faster vs. recommended)? | Stated mid-call without hedges. Anchored to the outcome. Silence after the number. |
| **Objection handling** | When the prospect pushes back: does the user ask a question to understand it, or immediately defend/discount? | Acknowledge, ask, then respond. No unprompted discounts. |
| **Closing** | Did the call end with a specific next step (date, who, what)? | A booked next conversation or a dated deliverable, agreed out loud. |
| **Listening for buying signals** | Prospect says "we've been struggling with…", "how soon could you…", "what would it cost to…" — did the user notice and follow up? | Signals get a follow-up question, not a pivot to pitch. |

## Client calls (advisory, coaching, project work)

| Dimension | How to spot it | Good looks like |
|---|---|---|
| **Directive vs. Socratic** | In coaching: does the user ask "what have you tried / what do you think?" or jump to "here's what I'd do"? Directive is fine in technical advisory when asked; in leadership coaching, evoking the client's own thinking is the job (ICF "Evokes Awareness"). | Coaching: mostly questions; advice offered as an option, with the client owning the next step. Advisory: recommendation-first, then reasoning. |
| **Over-explaining** | Multi-minute explanations of context, history, or alternatives the client didn't ask about. Restating a point three ways. | Answer, check ("does that land?"), stop. |
| **Handling disagreement** | When a team member defends a different approach: does the user acknowledge their rationale before reframing, or steamroll? | Name the other person's point, then state the decision-relevant question. |
| **Clarity of asks** | When the user needs something from the client (data, access, a decision): is it one clear sentence, or a back-and-forth? | One summary sentence with what, from whom, by when. |
| **Empowering vs. doing** | Does the user hand the client a principle they can reuse, or just fix the thing? | Names the principle ("labeling is a process you calibrate") so the team can apply it without the user. |
| **Accountability** | Does the user hold the client to their commitments, and hold themselves to their own? | Prior actions reviewed at the start; slipped ones re-dated explicitly rather than quietly. |
| **Time discipline** | Did the user respect the booked length? Offer a timebox when the client was distracted or busy? | Ends on time or negotiates an extension out loud. |

## Peer calls (accountability, masterminds, mentoring, co-planning)

| Dimension | How to spot it | Good looks like |
|---|---|---|
| **Give / take balance** | Share of time on the user's update vs. the other person's. Did the user ask about the other person's goals? | Roughly even, or by agreement. |
| **Asking for what they need** | When the user shares a draft, plan, or offer: do they ask a specific question, or just present and move on? | One pointed question ("which of these would you buy?") rather than a disclaimer. |
| **Feedback quality given** | Permission asked? Specific? Explains why? Backed by experience? Ends without an apology? | "Are you up for feedback?" → concrete → why → credibility. No "grain of salt" after. |
| **Commitments** | Does the user make 1–3 specific commitments with a date, or list everything they might do? | Few, concrete, checkable next time. |
| **Honest reporting** | Does the user report the gap between what they committed to and what they did, or curate wins? | "I said X, I did Y, here's what got in the way." |
| **Hard stops & etiquette** | Did the user announce a hard stop at the start? Miss someone's update because of it? | Hard stop in the first minute so the group can order around it. |

## Turning observations into the 3 + 3

1. List every moment with its quote and dimension.
2. Group by dimension across calls. Count occurrences.
3. Rank by (frequency × cost). A hedge that appears in four calls outranks a single long monologue. A slipped commitment to a paying client outranks a peer-call etiquette slip.
4. Pick the top 3 strengths and top 3 improvements. Everything else is cut or folded into one of the six.
5. For each, keep the single best quote (two if the pattern spans calls).
